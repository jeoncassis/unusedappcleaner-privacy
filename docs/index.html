안 쓰는 앱 정리 개인정보처리방침

최종 업데이트: 2026년 10월 30일

'안 쓰는 앱 정리'(이하 "앱")는 이용자의 개인정보를 소중히 여기며, 아래와 같이 개인정보처리방침을 안내합니다.

1. 수집하는 정보

정보어디로목적
광고 ID (Android 광고 식별자)Google AdMob광고(배너·전면 광고) 표시 및 광고 성과 측정

앱은 회원가입이나 로그인 없이 사용하며, 이름·이메일·전화번호 등 개인을 식별할 수 있는 정보를 수집하지 않습니다.

2. 기기 안에서만 처리하는 정보 (외부 전송 없음)

• 앱 사용 기록: 이용자가 허용한 '사용 정보 접근' 권한으로 각 앱을 마지막으로 실행한 시간을 읽어 화면에 표시합니다. 외부로 전송하거나 저장해 두지 않습니다.

• 설치된 앱 목록과 용량: 홈 화면에 아이콘이 있는 앱의 이름·아이콘·설치일·용량을 화면에 표시하는 데만 사용하며 외부로 전송하지 않습니다.

3. 사용하는 권한

권한용도
사용 정보 접근앱별 마지막 실행 시간 확인 (이용자가 설정에서 직접 허용하며 언제든 해제 가능)
앱 삭제 요청이용자가 고른 앱의 Android 삭제 확인 화면 호출
인터넷·네트워크 상태광고 표시
